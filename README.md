# Personal Accident Insurance Policy Administration & Claims Platform

A full-stack insurance management platform designed to handle the complete lifecycle of a Personal Accident insurance policy — from customer registration and underwriting to policy issuance, premium calculation, renewals, cancellations, and claims processing.

The system also integrates AI/ML models for **underwriting risk assessment** and **claim fraud-risk detection**, allowing risk-related decisions to be incorporated into the insurance workflow.

The project follows concepts commonly found in enterprise insurance platforms such as **Guidewire PolicyCenter and ClaimCenter**, while being implemented using React, Node.js, Express, MySQL, and machine learning.

---

## Overview

The platform provides two major areas of insurance operations:

* **Policy Administration** – customer management, policy creation, underwriting, premium calculation, renewals, and cancellations.
* **Claims Management** – claim registration, validation, AI-based fraud-risk assessment, review, and claim status management.

The AI components are integrated into the actual workflow rather than being separate demonstration models.

# 3. AI Underwriting Risk Assessment

The system includes a trained machine learning model that evaluates the risk associated with a policy applicant.

A **Multinomial Logistic Regression** model is used to classify applicants into three risk categories:

* Low
* Medium
* High

### Input Features

The model considers:

* Age
* Occupation hazard class
* Coverage type
* Sum insured
* Previous claims
* Customer tenure

### Risk-Based Premium Loading

The predicted risk level is directly incorporated into premium calculation.

| Risk Level | Premium Loading |
| ---------- | --------------: |
| Low        |              0% |
| Medium     |            +15% |
| High       |            +35% |

For example, a high-risk applicant receives a 35% premium loading on the calculated base premium.

### Model Performance

The underwriting model achieved approximately:

* **Test Accuracy:** 82%
* **Macro F1-Score:** 0.70

The model is intended to provide consistent risk assessment within the application workflow.

---

# 4. Premium Calculation

Premium calculation is based on the selected coverage type and sum insured.

The system first calculates the base premium and then applies the risk loading generated by the underwriting model.

### Formula

```text
Base Premium = (Sum Insured / 1000) × Base Rate

Final Premium = Base Premium × (1 + Risk Loading / 100)
```

### Coverage Rates

| Coverage Type |     Base Rate |
| ------------- | ------------: |
| Basic         | ₹2.5 / ₹1,000 |
| Standard      | ₹3.5 / ₹1,000 |
| Comprehensive | ₹5.0 / ₹1,000 |

A minimum premium floor of **₹500** is applied.

### Example

```text
Coverage       : Standard
Sum Insured    : ₹5,00,000
Base Rate      : ₹3.5 / ₹1,000

Base Premium   : ₹1,750

Risk Level     : Medium
Risk Loading   : 15%

Final Premium  : ₹2,012.50
```

This makes the AI underwriting result an actual part of the policy pricing workflow.

# 8. AI Fraud Detection

A separate machine learning model is used to identify potentially suspicious claims.

The fraud detection model uses **Binary Logistic Regression**.

### Features Used

The model evaluates factors such as:

* Claim amount relative to sum insured
* Time between policy start and incident
* Claim filing delay
* Previous claims
* Claim type
* Policy expiry proximity

The model produces a fraud-risk prediction that is incorporated into the claims workflow.

### Model Performance

The fraud detection model achieved approximately:

* **Accuracy:** 68%

Class balancing is used during training to reduce the effect of unequal class distribution.

The fraud model is used as a **decision-support mechanism**, helping identify claims that may require additional review.

# Machine Learning Pipeline

Both AI models are trained offline using Python and scikit-learn.

```text

      ↓

      ↓
Model Training
      ↓

      ↓
```

# Business Rules

The application implements several insurance-related business rules.

### Policy

* A policy belongs to a registered customer.
* A policy contains coverage and sum insured information.
* Policy status changes according to its lifecycle.
* Policy records are retained when renewed or cancelled.

### Underwriting

* Applicant information is evaluated before policy issuance.
* AI risk classification produces Low, Medium, or High risk.
* Risk classification determines premium loading.

### Premium

* Premium depends on sum insured and coverage type.
* Risk loading is applied after base premium calculation.
* Minimum premium is ₹500.

### Claims

* Claims are associated with existing policies.
* Claim timing and policy information are considered during assessment.
* AI fraud-risk analysis is performed using claim and policy features.
* Higher-risk claims can be marked **Under Review**.

# Installation & Setup

## Prerequisites

Make sure the following are installed:

* Node.js 18 or later
* npm
* MySQL 8 or later
* Python 3.x
* Git

---

## 1. Clone the Repository

```bash
git clone https://github.com/pavi17-R/Personal-Accident-Insurance-Policy.git
cd Personal-Accident-Insurance-Policy
```

---

## 2. Setup the Database

Create the database using the provided SQL schema:

```bash
mysql -u root -p < database/schema.sql
```

Alternatively, the `schema.sql` file can be executed through MySQL Workbench.

---

## 3. Setup the Backend

```bash
cd backend
npm install
```

Create a `.env` file using the provided `.env.example` and configure the MySQL connection details.

Start the backend:

```bash
npm run dev
```

---

## 4. Setup the Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

The Vite development server will provide the frontend application URL in the terminal.

---

# ML Model Training

The trained model files are already included in the repository, so retraining is not required for normal application usage.

To retrain the models:

```bash
cd ml
pip install pandas numpy scikit-learn
python train_models.py
```

The training process generates the updated model parameters used by the application.
